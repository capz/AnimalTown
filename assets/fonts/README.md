# Font sources

Unmodified files from the official Google Fonts repository:

* Gorditas Bold: `ofl/gorditas/Gorditas-Bold.ttf`, Git blob
  `a2ea4f6039ddb4830d5c9e8152c35c477d3e9562`.

The `OFL.txt` file is retained and copied into the disc. The build bakes Gorditas
Bold into a proportional GX IA8 atlas. Other in-game text uses the native IPL
font via the SDK; no firmware font files are stored here or copied into the ISO.
The console does not contain a TTF renderer. Fredoka was superseded by the
user's native IPL font requirement.

Source: https://github.com/google/fonts/tree/main/ofl/gorditas.
