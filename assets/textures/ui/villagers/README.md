# Picker portraits

Transparent renders of AnimalTown's existing, unmodified villager GLBs, baked
with `tools/bake-villager-portraits.py`. `provenance.json` binds every PNG to its
source model and renderer settings. See `docs/villager-picker.md` for regeneration,
GX conversion, memory budget and runtime ownership. These are picker-only assets;
gameplay continues to load the original models.
